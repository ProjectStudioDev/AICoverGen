# Dashboard Beheer ImpactFonds NL (Prototype)

Vanilla HTML/CSS/JS prototype voor fase 1.

## Starten
Open `index.html` direct in de browser of serve lokaal:

```bash
python3 -m http.server 8080
# en open http://localhost:8080/dashboard-impactfonds-nl/
```

## Fase 1 schermen
- Overzicht
- Aanmeldingen
- Verificaties
- Portaalbeheer & Klantregie
- Communicatie & Veiligheid
- CRM & Klantdossiers
- Personeel, Planning & Operatie
